# UASS - University Academic Support System

## Project Description
UASS is a web-based academic support system designed to improve communication between students and instructors inside the university.

The system allows students to:
- View courses
- View exams and marks
- Access support materials
- Add favorites
- Ask questions
- Change passwords

The system allows instructors to:
- Manage courses
- Create and manage exams
- Upload materials
- Answer student questions
- View student marks

---

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

---

## Database

The project uses MySQL database:
`university_academic_support_system`

---

## How to Run the Project

1. Install XAMPP
2. Place the project folder inside:
   `htdocs`
3. Start Apache and MySQL
4. Import the SQL file into phpMyAdmin
5. Open:
   `http://localhost/uass/login.php`
